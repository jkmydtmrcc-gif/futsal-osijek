# Grbovi klubova

Ovdje idu grbovi klubova iz tablice. Datoteku ubaci u ovu mapu i u
administraciji (Tablica i raspored → klub → Grb kluba) upiši putanju, npr.
`/uploads/grbovi/olmissum.png`.

Preporuka: PNG s prozirnom pozadinom, oko 200×200 px.

Dok grb nije upisan, redak u tablici pokaže inicijale kluba. Grbovi drugih
klubova nisu klupsko vlasništvo, pa se namjerno ne preuzimaju s interneta —
koristi one koje ti klub ili liga daju.
